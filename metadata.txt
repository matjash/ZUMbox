about=EN: Processing tools by ZUM d.o.o. for urban planning in Slovenia.
    - Import .WOR: loads all TAB layers from a MapInfo workspace into a new layer group, with automatic encoding detection.
    - 3tra: transforms vector layers between D48/GK and D96/TM using the official GURS triangle transformation model (v4.0).
    Tools are in the Processing Toolbox under ZUMbox; interface in Slovenian.
    SL: Orodja za procesiranje, razvita v ZUM d.o.o. za potrebe prostorskega načrtovanja.
    - Uvoz .WOR: naloži vse TAB sloje iz MapInfo delovnega prostora v novo skupino slojev, s samodejnim prepoznavanjem kodiranja.
    - 3tra: transformacija vektorskih slojev med D48/GK in D96/TM z vsedržavnim modelom trikotniške transformacije GURS (v4.0).
    Orodja so v orodjarni za procesiranje pod ZUMbox.
